# 路线图

## v0.2.0：统一语义事件接口

- 为视觉 token 增加 schema version、UUID、ISO 8601 时间、设备和位置字段。
- 增加 JSON Schema 和单元测试。
- 完成五类独立测试集并按源视频/场景重新划分。

## v0.3.0：SenseVoice 接入

- 固定 SenseVoice 模型标识、版本、依赖和音频采样率。
- 实现离线推理适配器。
- 输出转写、关键词/呼救事件、置信度和时延。
- 添加真实噪声环境测试，不把项目计划书描述当作完成证据。

## v0.4.0：可靠语义传输

- 定义 TLV 字段和版本协商。
- 实现 CRC 校验、ZeroMQ PUSH/PULL、HWM 和本地持久队列。
- 实现断线重连、幂等 event ID 和复网重发测试。

## v0.5.0：端边协同演示

- 融合视觉、语音与传感器事件。
- 岸基告警 UI。
- 使用 TC/NetEm 进行带宽、丢包、延迟、抖动和断网恢复实验。
